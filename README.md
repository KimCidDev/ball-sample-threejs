# Esfera 3D

Projeto inicial com **Three.js** + **Vite** que renderiza uma esfera 3D iluminada, com rotação automática e controle de órbita.

## Rodar localmente

```bash
npm install
npm run dev
```

Abre em http://localhost:5173

- Arrastar: gira a câmera
- Scroll: zoom

## Build de produção

```bash
npm run build
npm run preview   # http://localhost:4173
```
